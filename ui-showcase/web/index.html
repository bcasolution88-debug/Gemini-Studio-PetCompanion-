产品概览

一个以「领养 + 陪伴」为核心的宠物综合平台，将 AI 能力贯穿于匹配、健康、行为与社区问答全链路。

💗
智能领养

宠物卡片网格、多维筛选、AI 适配度评分、领养旅程追踪、准备清单、成果传单生成与成长时间轴。

💬
社区与专家

动态信息流（点赞/评论/收藏/分享）、带真实文献引用的专家问答、话题标签与发布器。

🤖
AI 助手

对话式问诊、症状自检、品种智能匹配、科学膳食规划三合一，支持语音播报与上下文关联。

🗺️
地图与追踪

周边诊所/用品店地图检索、实时 GPS 追踪、地理安全围栏、紧急求助与追踪器指令面板。

📓
健康日志

体重趋势、情绪标签、活动记录、AI 健康洞察、照护routine与成就徽章等级系统。

🌏
国际化 / 主题

中文 / English 实时切换（Context + 事件广播）、浅色/深色主题持久化、微交互动效音效开关。

01

前后端架构

单仓全栈：Vite 中间件挂载在 Express 上，同一端口同时提供 SPA 与 API；AI 调用带多模型降级与离线兜底。

🧱 技术栈分层

React 19 + TypeScript UI 层
Tailwind CSS 4 + Motion 样式 / 动效
Recharts · D3 · Leaflet 可视化
Express 4 + Vite Middleware 服务层
@google/genai (Gemini) AI 层
Firebase Auth · jsPDF 认证 / 导出
localStorage（离线持久化） 数据

⚙️ AI 请求链路

1 · 前端 fetch POST
2 · Express 路由校验入参 JSON
3 · generateContentWithFallback 4 模型降级
4 · 规则引擎兜底响应 离线可用

模型顺序：gemini-3.5-flash → gemini-3.1-flash-lite → gemini-flash-latest → gemini-3.1-pro-preview， 任一失败自动切换；全部失败时返回本地规则化文案，保证 UI 永不空白。

组件类型职责说明
